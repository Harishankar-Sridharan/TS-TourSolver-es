# 4. ¿Qué navegadores y sistemas son compatibles con TourSolver?

TourSolver es compatible con lo siguiente:

* **Google Chrome**
* **Mozilla Firefox**
* **Microsoft Edge**
* **Apple Safari**&#x20;

A continuación hay una lista de versiones de navegadores que han sido probadas/validadas con TourSolver:

* Google Chrome: versión 142 y superiores
* Mozilla Firefox: versión 145 y superiores
* Microsoft Edge: versión 142 y superiores
* Apple Safari: versión 26 y superiores

Las versiones de navegador que aparecen a continuación no están probadas ni son compatibles con TourSolver:

* Microsoft Internet Explorer 9, Microsoft Internet Explorer 10, Microsoft Internet Explorer 11

#### Aplicación móvil TourSolver

* **Android**
* **iOS**

Aquí está la lista detallada de versiones de los sistemas operativos móviles probados/validados con TourSolver:

* Android: Entre 8.0 y 15
* iOS 15.5 y posteriores

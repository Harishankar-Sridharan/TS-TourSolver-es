# 6. ¿Cómo priorizar el menor número posible de km / el mayor número de clientes planificados?

Durante la optimización, puedes establecer prioridades en el **Configuración de Optimización** bajo el **Prioridades de Optimización** pestaña. Ajusta los siguientes parámetros según tus objetivos:

* **Reducir kilómetros**: Bajo / Normal / Importante
* **Reducir la ventana de tiempo de trabajo**: Bajo / Normal / Importante
* **Maximizar el número de visitas**: Bajo / Normal / Importante
* **Usar la menor cantidad posible de recursos**: Bajo / Normal / Importante

Estas configuraciones influyen en cómo el algoritmo de optimización equilibra tus restricciones.\
**Consejo:** Asigna diferentes niveles de prioridad a cada parámetro para obtener mejores resultados. Establecer todas las restricciones en “Importante” normalmente **no** produce resultados óptimos.
